# Portfolio Frontend

Frontend application for my personal portfolio.

## Tech Stack

- React 19
- TypeScript
- Vite
- Material UI
- ESLint
- Prettier

## Requirements

- Node.js
- npm

## Installation

### Getting Started

Clone the repository:

```bash
git clone https://github.com/r-emanuel-sceppaquercia/portfolio.git
```

Navigate to the frontend module:

```bash
cd portfolio/Modules/Frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
